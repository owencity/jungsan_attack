# 앱 아이콘

`icon.html`을 브라우저로 열면 4개 시안이 512 / 96 / 48px로 보인다. 색·크기·기울기를 고쳐서 다시 뽑을 수 있다.

## 시안

| | 내용 | 48px 가독성 |
|---|---|---|
| A | 정산 | 보통 |
| **B** | **정산 (−6° 기울임)** | **보통 — 추천** |
| C | 어택 | 보통 |
| D | ÷ 심볼 | 좋음 |

**B 추천.** 기울기가 "어택"의 에너지를 만들고, 브랜드명 앞 두 글자라 검색·연상이 붙는다.
D는 작은 크기에서 가장 선명하지만 브랜드가 안 읽힌다. 나중에 스플래시나 파비콘용으로 쓸 수 있다.

## 구조

- 배경: 시안 3단 그라디언트 + 좌상단 광, 흰 거품 원
- 글자: 흰 아웃라인(48) → 진한 핑크 아웃라인(27) → 핑크 그라디언트 채움 → 상단 광택
- 그림자: dy 13 / blur 11

색을 바꾸려면 `defs()` 안의 `bg` `pink` 그라디언트만 고치면 된다.

## 출력물

`icon_{시안}_{크기}.png` — 1024 / 512 / 192

- Play Store 등록: 512×512
- Android 앱 아이콘: 192 (xxxhdpi는 별도 생성 필요)
- App Store: 1024×1024

**Android는 적응형 아이콘(Adaptive Icon)을 요구한다.** 배경 레이어와 전경 레이어를 나눠야 하고, 안전 영역이 중앙 66%다. 지금 시안은 글자가 중앙에 모여 있어 그대로 전경으로 쓸 수 있지만, 배경 거품은 잘릴 수 있으니 배경 레이어로 분리할 것.

## 저작권

버블 레터링·핑크 온 시안·광택 처리는 특정 작품이 아니라 **양식**이므로 문제되지 않는다.
다만 앨범 커버 이미지 자체, 그 로고의 글자 형태를 그대로 따라 그린 것은 사용하지 말 것.
여기 아이콘은 Noto Sans CJK KR Black(오픈 라이선스)에 아웃라인을 쌓아 만든 것이라 폰트 라이선스도 자유롭다.

## 2차 시안 — "어택" 표현 (`icon2.html`)

÷ 를 텍스트가 아니라 도형(원·막대·원)으로 그려서 그 위에 타격 요소를 얹었다.

| | 내용 | 48px | 비고 |
|---|---|---|---|
| E | 총알구멍 + 크랙 | 약함 | 구멍이 작아 점으로 뭉갬 |
| F | 조준선 | 좋음 | 차분함. "정확히 조준한다"로도 읽힘 |
| **G** | **임팩트 폭발 (노랑)** | **매우 좋음** | **추천 — 목록에서 가장 눈에 띔** |
| H | 관통 궤적 | 보통 | 요소가 많아 작은 크기에서 뭉갬 |

**G 추천.** 노란 버스트가 시안 배경과 보색이라 아이콘 목록에서 확 튀고, 48px에서도 형태가 살아남는다.
코믹 임팩트라 버블 레터링 톤과도 맞는다.

### 총기 묘사는 피할 것

실제 총 형태를 그리면 스토어 연령 등급이 올라갈 수 있다. 위 시안은 전부 **추상적 타격 표현**(구멍·조준선·임팩트·궤적)이라 안전하다.
"어택"의 느낌은 총 자체가 아니라 **부딪힌 흔적**으로 내는 것이 톤에도 맞고 심사에도 안전하다.
