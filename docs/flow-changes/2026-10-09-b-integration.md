# 2026-10-09 — 웹을 정산 단위(B) 서버에 붙이며 나온 것

웹 v3를 `feat/backend-v4`(769dd4c)에 로컬로 붙여 끝까지 돌려봤다(만들기 → 차수 → 링크 참여 → 다음 차 총무 →
정산 → 송금 대기). 계약대로 동작했고, 아래는 그 과정에서 서버 쪽에서 고칠 것과 CTO가 정할 것이다.
FC-015(같은 술자리의 새 총무)는 `docs/host-settlement-units` 브랜치에 있어 번호를 016부터 쓴다.

## FC-016 시간이 9시간 밀려 내려온다 — 로컬 프로필

- **상태:** 열림
- **바뀐 흐름:** 없음. 타임라인 날짜가 하루 뒤로 보이는 버그(10/9 15시 KST에 만든 기록이 "10/10")
- **백엔드 영향:** 로컬에서 15:25(KST)에 만든 기록이 `"createdAt": "2026-10-09T15:25:58Z"`로 내려온다 — 한국 시각에
  `Z`가 붙었다. 원인으로 보이는 곳: `application-local.yml`의 JDBC URL에 `serverTimezone=UTC`(또는 `connectionTimeZone=UTC`)가
  없다. `application-prod.yml`에는 있다. 그래서 **운영에서는 안 생길 가능성이 높지만**, 로컬과 운영이 다르면
  로컬 검증이 시간 버그를 못 잡는다.
- **기존 문서와 충돌:** 스키마 결정 "DATETIME은 UTC로 저장" 규율과 어긋난 결과
- **반영할 곳:** `application-local.yml` URL을 운영과 맞추기. 운영 첫 배포 뒤 응답 한 건으로 `Z` 시각이 실제 UTC인지 확인

## FC-017 타임라인 금액에 천 단위 쉼표가 없다

- **상태:** 열림
- **바뀐 흐름:** 정산방 타임라인(R1)에 "1차 184000원을 넣었어요"로 보인다. 화면의 다른 금액은 모두 "184,000원"
- **백엔드 영향:** 타임라인 시스템 문구를 서버가 만든다 — 금액을 `184,000`으로 포맷해서 넣는다.
  이미 저장된 문구는 7일 뒤 삭제되니 소급 수정은 필요 없다
- **반영할 곳:** 타임라인 문구 생성부

## FC-018 알림 `title`에 종류 코드가 그대로 들어 있다

- **상태:** 열림
- **바뀐 흐름:** 알림함(N1) 한 줄의 제목. 지금 응답은 `title: "SETTLED"`, 사람이 읽을 문장은 `body`에만 있다
- **백엔드 영향:** `title`은 사람이 읽는 짧은 제목(FC-005 문구)으로, 종류는 이미 있는 `type`으로 구분한다.
  당분간 웹은 `body`를 제목 자리에 쓰고 있다 — 서버가 고치면 프론트도 `title`로 되돌린다
- **반영할 곳:** 알림 생성부, `API.md` 알림 응답 예시

## FC-019 총무 본인의 차수 응답 — 기본값을 어떻게 둘까

- **상태:** 결정 필요
- **바뀐 흐름:** 총무가 차수만 넣고 자기 응답을 안 하면, 정산하기(R3)에서 **자기 이름이** "응답이 없어 전 차수
  참석·알코올로 계산돼요" 경고에 뜬다("박재훈 응답 넣기"). 총무는 차수를 넣은 사람이라 응답할 화면을 따로 찾지 않는다
- **백엔드 영향:** 선택지에 따라 다르다(아래)
- **결정 필요:** 총무가 그날 술을 안 마셨을 수 있다(몸이 안 좋음, 운전 등). 그래서 **보이지 않는 기본값은 안 된다.**

  | 안 | 동작 | 서버 | 대가 |
  |---|---|---|---|
  | **A (추천)** | 차수 입력(R2)에 "나는 이 차수에 [불참][논알코올][알코올]" 한 줄. **알코올이 눌린 채 보이고** 한 번 눌러 바꾼다. 저장하면 차수와 내 응답이 같이 들어간다 | 없음 — 프론트가 차수 저장 뒤 `PUT U/responses/me` | R2에 버튼 한 줄 추가 |
  | B | 서버가 차수를 만들 때 총무 응답을 ALCOHOL로 자동 생성 | 차수 생성 트랜잭션에 응답 한 줄 | 안 마신 날 틀린 금액이 조용히 나온다 |
  | C | 지금대로(미응답 → 정산 때 자동 ALCOHOL) | 없음 | 총무가 자기 이름 경고를 보고 직접 넣어야 한다 |

  추천은 A. 대부분은 마시니 한 번도 안 눌러도 되고, 안 마신 날은 같은 화면에서 한 번 누르면 된다.
  결제자가 총무가 아닌 차수("다른 사람이 냈어요")에서도 총무 본인 응답만 이렇게 받는다 — 결제자 응답은 결제자가 한다
- **반영할 곳:** A면 `SCREENS.md` R2, 서버 변경 없음(`프론트만`으로 닫음). B면 `API.md` 차수 생성

## 그 밖 — 이미 다른 항목에 있는 것

- 앱 로그인(Bearer 교환)·애플 로그인·탈퇴·`returnTo`는 FC-014 P0 그대로 **아직 시작 전**이다. 앱은 이것 없이는 서버에 붙을 수 없다
- 스푼 지급 규칙(총무가 여럿일 때)은 `SETTLEMENT_UNITS.md` §7 미결 그대로 — 그때까지 서버 모드 웹은 스푼 버튼에 "곧 열려요"를 띄운다
