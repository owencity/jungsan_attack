# FC-032 비회원 이름 정정·동일 브라우저 재방문

- **상태:** 백엔드·웹 운영 반영됨 · 앱 배포 검증 진행 중
- **결정:** CTO 2026-11-01. 가입 없이 같은 브라우저에서 본인 응답을 복원하고 이름 오타도 수정한다. 다른 브라우저는 총무에게 정정을 요청한다. 이름 선택만으로 본인 권한을 복구하지 않는다.
- **백엔드 영향:** 기존 본인 응답 PUT에 선택적 displayName/expectedDisplayName을 추가해 이름과 응답을 원자적으로 저장한다. 총무는 자기 OPEN 명단의 비회원 이름만 PUT participants/{pid}/name으로 정정한다. 성공 204.
- **보존:** participantId·브라우저 연결·차수 응답·스푼 지급 사건을 새로 만들지 않는다. 이름 정정 자체는 보상을 지급하지 않는다. 회원 이름/로그인 프로필은 이 API로 변경하지 않는다.
- **공유 이름:** 이름은 술자리 전체에서 공유한다. 해당 참여자의 소속 이력 중 확정된 정산이 하나라도 있으면 이름 변경을 거절한다. 모든 단위를 ID 순서로 잠근 후 술자리를 잠그고, 영향을 받는 OPEN 명단의 revision을 올린다. 미리보기 후 이름이 바뀌면 다시 확인해야 한다.
- **충돌:** 현재 이름이 expectedDisplayName과 다르면 409 GUEST_NAME_STALE. 이미 원하는 이름이면 재시도는 무변경 성공. 확정 이름은 409 GUEST_NAME_LOCKED. 정산 단위가 잠금 획득 중 추가되면 409 SETTLEMENT_INPUT_CHANGED 후 재조회한다.
- **화면:** 비회원은 내 응답 수정에서 이름과 참석을 함께 수정. 다른 기기/쿠키 삭제 시 총무에게 정정 요청 안내. 총무 웹·앱은 참여자 관리에서 이름 정정. 데모는 가상 자료임을 유지.
- **기존 계약:** FC-028의 참여 POST 이름 불일치 거절은 유지하고 수정 PUT만 확장한다. 스키마·core·인증 방식 변경 없음.
- **후속:** 본인 확인 없는 기기 간 복구·개인 수정 링크·비밀번호·회원 연결은 구현하지 않는다.
- **검증:** 서버 230개 테스트, 실제 MySQL/HTTP 비회원 66개·스푼 회귀 23개 통과. CI 41289287779 성공. 운영 서버 8137cb9 배포와 health 200·미인증 수정 401 확인. 실제 운영 계정으로 정정 성공을 확인한 결과는 아니다.
- **구현 위치:** 서버 PR54, 웹 PR2(profile), 앱 PR5(jungsan_app). 스터디용으로 병합하지 않는다. 웹 289개·Android 232개 로컬 테스트 통과. 배포별 최신 결과는 docs/operations/fc032-release-2026-11-01.md에 기록한다.
