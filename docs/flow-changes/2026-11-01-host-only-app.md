# FC-030 운영 앱은 총무 전용 · 참여자는 응답 웹과 정산 이미지

- **상태:** 프론트만 — CTO 결정 2026-11-01. 기존 FC-028/029의 서버 계약으로 제공한다.
- **바뀐 흐름:** 총무는 로그인 앱에서 금액 입력 → 응답 링크 공유 → 전체 명단 검토·제외 → 예상 금액 확인·명시적 확정 → 정산표 PNG 저장 → 직접 카카오톡 전달. 참여자는 가입 없는 웹에서 이름·차수별 참석/음주만 보내고 총무가 공유한 이미지로 송금 대상/금액을 확인한다.
- **앱:** 운영 계정에서는 참여 중 탭과 참여자 알림을 숨기며 이전 참여 경로는 웹 응답으로 안내한다. 정산 확정 후 핵심 동작은 이미지 저장이다. 대화 UI는 운영 동선에서 제외한다. 총무 자신의 참석/음주 선택·입금 확인·계정 삭제는 유지한다. 심사/개발의 가상 역할 전환은 운영과 분리해 기존 검증용으로 유지한다.
- **백엔드 영향:** URL·DTO·스키마·계산·인증 변경 없음. 기존 회원/비회원 금액·송금·메시지·신고/차단 API는 이전 앱과의 호환을 위해 유지한다. 앱 화면을 숨기는 것은 서버 권한 검사를 대체하지 않는다. 명단·계산의 참여자 레코드도 삭제하지 않는다.
- **정확성:** 표는 서버의 정수 표시값·확정 송금 스냅샷을 사용하며 프론트에서 재계산하지 않는다. 상단에 수취인별 최종 보낼 금액, 아래 차수별 안주·술·조정 근거를 표시한다. 예상 금액은 이미지 저장을 허용하지 않는다. 입금 완료와 금액 확정을 구분한다.
- **기존 문서와 충돌:** FC-007의 참여 중 탭과 FC-014의 참여자 앱 화면은 운영 앱의 신규 흐름에서 사용하지 않는다. 과거 API는 폐기하지 않는다. FC-029 자동 계산/총무 확정 정책은 그대로다.
- **반영:** 앱 PR4와 웹 PR1, REQUIREMENTS v7. 웹 공유 문구/이미지 안내도 앱 사용을 요구하지 않도록 맞춘다. 운영 배포·TestFlight·실기기 저장/첨부 검증은 PR별 실행 결과로 구분한다.
