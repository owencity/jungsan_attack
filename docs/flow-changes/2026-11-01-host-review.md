# FC-029 응답 전용 참여 · 총무 확인 후 확정

- **상태:** 열림 — CTO 결정 완료(2026-11-01), 구현·검증 중. 운영 미적용.
- **바뀐 흐름:** 참여자는 모바일웹에서 이름과 차수별 불참/논알코올/알코올만 제출한다. 제출 완료 안내 후 닫거나 본인 응답을 수정한다. 방·계좌·송금 화면으로 이동하지 않는다. 총무는 앱에서 명단과 예상 금액을 확인하고 잘못된 응답자를 제외한 뒤 직접 확정한다.
- **결정 근거:** 공개 링크의 장난 응답을 총무가 확인하기 전에 자동 확정하면 명단을 수정할 수 없다. CTO가 ‘자동 계산 + 총무 확인 후 확정’을 선택했다.
- **백엔드 영향:** 응답·차수·인원·명단 변경은 OPEN을 유지한다. 목표 인원은 안내용이며 선착순 선택·자동 제외·자동 송금 스냅샷을 만들지 않는다. 계산 대상은 해당 단위 ACTIVE 명단 전원이다. 기존 preview/table은 core로 예상 금액을 계산하고 결과를 저장하지 않는다.
- **확정:** 기존 POST /api/v1/gatherings/{gid}/settlement-units/{id}/settlement만 확정한다. 총무 권한, OPEN, inputRevision/inputHash 검증과 단위 잠금을 유지한다. 미리보기 후 응답·제외가 바뀌면 409 SETTLEMENT_INPUT_CHANGED, 다시 미리보기해야 한다.
- **제외:** 기존 DELETE .../participants/{participantId} 204. 해당 단위 응답만 지우고 다른 단위·공유 신원은 보존한다. 총무와 결제자는 제외할 수 없다. 제외된 비회원의 재제출은 403이다.
- **계약 호환:** URL·DTO·DB 스키마는 유지한다. headcount(2..50)는 예상 인원, autoSettlementError는 전원 응답 후 계산 검증 오류로 유지한다. 확정 전 누락 응답의 DRANK/AUTO 기본값은 기존 규칙이며 미리보기에서 표시한다. 기존 확정 건은 자동으로 되돌리지 않는다.
- **참여자 범위:** 응답 전용 화면은 비회원 링크 흐름에 적용한다. 기존 회원 API·개인 금액/보냈어요 API는 호환 목적으로 유지하며, 새 화면은 호출하지 않는다. 로그인 중인 링크 접근은 기존 신원을 중복 생성하지 않도록 별도 확인한다.
- **표시:** 음료는 기존처럼 안주에 포함하고 ‘안주’로만 표시한다. 정산 확정 후 총무가 최종 송금액을 강조한 전체 가로 정산표 PNG를 저장·공유한다. 미확정 표는 예상 금액으로 표시한다.
- **기존 문서와 충돌:** FC-020의 전원 응답 자동 확정·선착순 인원 제외를 대체한다. FC-028의 참여자 개인 금액/보냈어요 화면은 새 비회원 흐름에서 사용하지 않는다. 엑셀 파일 다운로드는 만들지 않는다.
- **검증:** 전원/동시 응답 후 OPEN·스냅샷 0건, 초과 명단 보존, 총무 제외 후 재계산·오래된 해시 거절, 총무만 확정, 중복 확정 1건, 되돌린 뒤 응답해도 OPEN, 웹·앱 계약 일치.
