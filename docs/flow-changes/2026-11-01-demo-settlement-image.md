# FC-033 공개 데모에서 샘플 정산표 이미지 저장

- **상태:** 반영됨 · 앱 PR6(a475264), Android 232개·iPhone 6개·iPad 3개 검증 통과, TestFlight17 업로드 성공. API/DB 변경 없음.
- **근거:** FC-027 심사 접근 준비의 연장이다. 빌드16에서 정산표 버튼은 실제 API 연결에만 나타나고 이미지 검사는 디버그 실행 인자를 사용했다. 심사자는 공개 데모에서 핵심 이미지 저장을 확인할 수 없다.
- **바뀐 흐름:** 로그인 없이 데모 체험 → 이름 확인 또는 가상 역할 선택 → 내 술자리의 `샘플 정산표 보기·저장` → 체험용 PNG 저장 창. 뒤로가기로 데모 홈에 돌아간다.
- **범위:** 고정된 가상 25명·25,000원 예시를 실제 이미지 생성/플랫폼 저장 코드로 전달한다. 편집 중인 데모 술자리의 결과가 아니라는 안내를 표시하며 이미지에도 `체험용 · 실제 송금 없음`을 넣는다. 공개 데모에서만 진입하며 실제 API·계정·스푼은 변경하지 않는다.
- **백엔드 영향:** API·DB·계산 규칙 변경 없음. 실제 정산표는 기존 서버 금액을 그대로 사용한다. 개인 데이터/토큰/계좌는 예시에 넣지 않는다.
- **검증:** 기존 이미지 XCTest를 디버그 바로가기 대신 공개 로그인 화면의 데모 버튼에서 진입하도록 변경한다. 파일명과 선택 가능한 저장 메뉴를 확인하며 기기 사진 보관함 저장 완료와는 구분한다.
- **출시:** 빌드17에 포함된다(빌드16에는 없음). [검증·업로드 기록](../operations/fc033-release-2026-11-01.md). Apple 처리 상태·App Store 재심사 제출은 별도이며 심사 통과를 뜻하지 않는다.
