# 2026-10-04 — L2 이름 확인

웹·Android·iOS 세 플랫폼에 L2 이름 확인 화면을 넣었다(목데이터). 서버가 받쳐야 할 것을 적는다.

## FC-013 첫 로그인 이름 확인 — `needsName`, 이름 저장 API, 길이 규칙

- **상태:** 열림 (아래 "결정 필요" 한 가지는 추천안을 기본값으로 둔다)
- **바뀐 흐름:**
  - **L2** — 첫 로그인 뒤 H1로 가기 전에 한 번. 카카오 닉네임이 미리 채워져 있고, 대부분 그대로
    [이 이름으로 시작]을 누른다. 확인하면 다시 묻지 않는다.
  - **P1(링크로 처음 들어온 사람)** — 화면을 하나 더 거치지 않게 P1 안에 이름 칸을 같이 둔다.
    [참여하고 응답 완료] 한 번에 **이름 확인 → 참여** 순서로 처리한다. 그래서 타임라인 첫 줄이
    확인한 이름으로 나간다("서연이님이 들어왔어요").
  - 이름 규칙: 앞뒤 공백을 뗀 뒤 **1~10자**. 글자 수는 **유니코드 코드포인트** 기준이다(이모지 🍺 하나 = 1자).
    문구: 빈 값 `이름을 넣어주세요`, 초과 `이름은 10자까지예요`.
  - 이름을 확인하면 내가 들어간 **모든 정산방**(완료된 방 포함)에 새 이름이 보인다.
- **백엔드 영향:**
  - **DB** — `users.display_name`은 `DOMAIN_DB_DESIGN_V2` §4.1에 이미 있다. 첫 로그인 UPSERT 때
    **비워 둔다(NULL)** — NULL이면 "아직 확인 안 함"이다. 별도 플래그 컬럼은 필요 없다.
  - **`GET /auth/me`** — 응답에 두 값을 더한다.
    ```json
    { "id": 12, "displayName": null, "suggestedName": "🌸봄이🌸", "needsName": true, ... }
    ```
    - `needsName = display_name IS NULL`
    - `suggestedName` = 카카오 닉네임(입력칸 기본값). 확인 뒤엔 `displayName`만 보면 된다.
    - `API.md` §2.1의 미정 사항("최초 로그인 안내를 `/auth/me`에 얹을지 리다이렉트 쿼리로 붙일지")을
      **`/auth/me`에 얹는 쪽**으로 프론트가 붙였다. 새로고침해도 다시 알 수 있어서다.
  - **새 API** — `PUT /api/v1/users/me/display-name` `{ "displayName": "동규짱" }`
    - 서버도 같은 규칙으로 검증한다(trim, 1~10 코드포인트). 어기면 400 + 위 문구.
    - 성공하면 갱신된 `me`를 돌려준다. 같은 값으로 다시 불러도 성공(멱등).
  - **P1 참여** — 프론트는 이름 저장 → 참여(FC-009) 두 요청을 차례로 보낸다. 이름 저장이 실패하면
    참여를 보내지 않는다. 한 요청으로 합칠 필요는 없다(이름은 사용자 단위라 정산방 트랜잭션과 무관).
  - **참여자 이름** — `participants.name`을 두지 않고 `users.display_name`을 조인한다(DOMAIN §4.1 그대로).
    그래서 이름을 바꾸면 완료된 방까지 바뀐다 — 프론트 목데이터도 이렇게 맞췄다. 따로 전파할 일은 없다.
  - **타임라인** — 시스템 줄 문구("○○님이 들어왔어요")는 만들 때의 이름으로 굳는다(본문 저장). 이름을
    나중에 바꿔도 지난 줄은 그대로다. 프론트도 그렇게 보여준다.
- **기존 문서와 충돌:**
  - `API.md` §2.2 — `/auth/me`가 `nickname`(카카오에서 읽은 값)을 돌려주고 "카카오에서 닉네임을
    바꾸면 바로 반영된다"고 적혀 있다. v3에선 화면에 보이는 이름이 `display_name`이라 이 설명과 어긋난다.
  - `API.md` §2.1 — `firstLogin`을 어디에 둘지 미정. 위처럼 `needsName`으로 대신한다.
- **결정 필요:** 이름을 확인한 뒤 **카카오 닉네임이 바뀌면** `display_name`도 따라 바꾸나?
  - (추천) **따라 바꾸지 않는다.** 사용자가 직접 확인한 이름이 정산방에서 갑자기 바뀌면 친구들이 못 알아본다.
    카카오 닉네임은 `suggestedName`(L2 기본값)에만 쓴다. 대가: 카카오 닉네임을 바꾼 사람은 정산어택 이름이 옛것으로 남는다.
  - 따라 바꾼다 — 로그인 때마다 덮어쓰면 L2 확인이 의미가 없어진다.
- **반영할 곳:** `API.md` §2.1·§2.2(`/auth/me` 응답, 이름 저장 API), `DOMAIN_DB_DESIGN_V2.md` §4.1
  (`display_name` NULL = 미확인, 길이 규칙)
