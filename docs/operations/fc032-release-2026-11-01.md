## 남은 실제 기기 확인

- 2026-11-01 CTO 확인: iOS에서 복사는 잘 되며 카카오톡 미설치 시 앱이 열리지 않는 것으로 보인다고 보고했다. 확인한 빌드 번호는 지정하지 않았다. 미설치 실패 후 클립보드 유지·오류 안내, 이름/참석 정정과 중복 방지는 별도 확인 대상이다.
- CTO는 TestFlight16이 표시되면 비회원 이름 정정 후 기존 응답·스푼 유지와 중복 방지를 확인하기로 했다. 아직 결과를 받은 상태는 아니다.
- 이후 CTO는 현재 기능이 잘 동작하는 것으로 보고 다음 개발 진행을 승인했다. 항목별 기기 결과를 새로 제공한 것은 아니며, 이 확인을 후속 개발의 선행 조건으로 두지 않는다.

- 같은 카카오톡 브라우저에서 링크 재방문 → 기존 응답/이름 수정.
- 다른 브라우저는 본인 기록을 이름 선택으로 가져오지 않고 총무에게 정정 요청.
- 총무가 명단 이름 정정 → 참가자 화면 재조회 → 확인 후 정산 확정.
- participantId와 스푼 유지, 최종 이미지에 정정된 이름·송금액 표시.
- 데모의 가상 회원을 실제 비회원으로 바꾸지 않았다. 위 검증은 실제 링크로 확인한다.
