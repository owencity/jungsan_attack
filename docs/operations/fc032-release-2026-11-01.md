## 남은 실제 기기 확인

- 같은 카카오톡 브라우저에서 링크 재방문 → 기존 응답/이름 수정.
- 다른 브라우저는 본인 기록을 이름 선택으로 가져오지 않고 총무에게 정정 요청.
- 총무가 명단 이름 정정 → 참가자 화면 재조회 → 확인 후 정산 확정.
- participantId와 스푼 유지, 최종 이미지에 정정된 이름·송금액 표시.
- 데모의 가상 회원을 실제 비회원으로 바꾸지 않았다. 위 검증은 실제 링크로 확인한다.
