# FC-033 공개 데모 정산표 · 2026-11-01

## 변경과 현재 범위

- CTO는 기존 기능이 정상 동작하는 전제로 다음 개발을 진행하도록 지시했다. 이는 이름 정정·응답 보존 등 모든 항목을 실기기에서 개별 확인했다는 기록은 아니다.
- 공개 데모 홈에서 `샘플 정산표 보기·저장`을 누르면 기존 이미지 생성·플랫폼 저장 경로가 열린다. 가상 25명·25,000원이며 편집 중인 데모 술자리와 독립적이다. 화면과 PNG에 체험용·실제 송금 없음 표시가 있다.
- 실제 API 연결 앱에는 이 데모 메뉴를 넣지 않았다. 서버/API/DB/계산 규칙과 웹 운영 배포는 변경하지 않는다.
