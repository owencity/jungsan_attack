→ groups(id)

→ users(id)
 bigint NOT NULL — 주최자 계정

술자리(Gathering)를 묶는 컨테이너. 번개(FLASH)와 주기(RECURRING) 두 종류다. 참여는 자동화하지 않는다(ADR-009) — group_members 는 소속만 기록한다

컬럼타입NULL 기본값설명
idPK bigint NOT NULL — 그룹 고유 id
name varchar(50) NOT NULL — 그룹 이름. 예: 신림팸
created_by_user_idFK
→ users(id)
 bigint NOT NULL — 그룹을 만든 사용자. 반드시 OWNER 로 group_members 에도 존재해야 한다(애플리케이션이 같은 트랜잭션에서 보장)
created_at datetime NOT NULL — 그룹 생성 시각. UTC
group_type varchar(10) NOT NULL RECURRING FLASH(번개, 1회성) | RECURRING(주기적). 값 검증은 애플리케이션 계층이 한다. FLASH 는 생성 시 Gathering 1개를 함께 만들고, 정산 확정 +14일에 소프트 삭제된다.
share_tokenUK varchar(12) NULL — 모임 가입 링크 토큰(/gr/{token}). 12자·62종·SecureRandom. 로그에 남기지 않는다(SPEC §10). 기존 행을 위해 nullable 로 두고 애플리케이션이 생성 시 항상 채운다.
deleted_at datetime NULL — 소프트 삭제 시각. UTC. NULL 이면 살아있다. 모임 목록 조회는 deleted_at IS NULL 로 거른다. 결제 내역(id 직접 접근)은 이 값을 무시하고 그대로 보여준다.
delete_scheduled_at datetime NULL — 삭제 예정 시각. UTC. FLASH 모임의 정산이 확정될 때 확정시각 + 14일로 채운다. RECURRING 은 항상 NULL — 만료가 없다. 스케줄러가 이 시각을 지난 행의 deleted_at 을 채운다.
