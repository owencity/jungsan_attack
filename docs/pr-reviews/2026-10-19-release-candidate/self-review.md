# 출시 후보 통합 자체 점검

구현자의 자체 점검이다. 외부 리뷰·CTO 승인·운영 적용과 구분한다.

- 범위: main 3eb5254 이후 #32 Caddy, #33 404, #35 알림, #36 Boot4, #37 기존 데이터 전환을 통합한다. OCR은 보류하고 사진 수신 미커밋 작업을 다른 트리에 보존했다.
- 통합: #37 28ab9dd와 Caddy 5f318cf의 이력을 merge commit으로 보존했다. 충돌은 DEVLOG와 ADR 인덱스 두 곳뿐이며 둘 다 남겼다. CI는 Boot3 기준 빌드·MySQL 전환과 Caddy 경로/방화벽 검사를 모두 유지한다.
- 코드: 통합 뒤 server/core/Gradle 소스는 #37과 동일하다. 새 업무 정책·API·DB·의존성을 추가하지 않았고 core 순수 계산·Liquibase 적용 이력을 유지한다. 기존 Java/Kotlin 독립 구현·동등성 테스트는 같은 후보에서 실행한다.
- 권한/불변: 기존 auth guard·JSON 호환·정산/송금·알림·로그아웃/탈퇴·재시도 테스트를 유지한다. CI의 실제 MySQL/HTTP는 mock과 구분한다. 이번 통합에서 N+1/행 잠금/거래 흐름을 새로 바꾸지 않았다.
- 운영 경계: Caddy 설치·방화벽 코드는 기존 검증을 그대로 가져오고 운영 설치·DNS·설정을 다시 실행하지 않는다. 새 배포의 실패 복원도 CI 모의 환경 범위이며 운영 복원을 실행한 기록이 아니다.
- 로컬: Core54/서버146, 실패·오류·건너뛰기0, compileKotlin·bootJar 성공. 방화벽8/DNS9, Bash 구문 통과. 통합 CI 결과는 별도 ci-source.json에 보존한다.
- 공개 관측: 10/19 health200/auth401/CORS200/metrics404. 없는 API500은 #33 미배포 상태를 드러낸다. 비인증 단건 관측으로 실계정 로그인·성능·최신 후보 배포를 주장하지 않는다.
- 연결: FC023의 headcount1 전송은 현재 웹/앱 소스에도 남아 있다. 최소2 서버 계약은 유지하고 프론트 수정 방법을 FC에 남겼다. 읽은 blob/파일 해시는 빌드·운영 동일성 근거가 아니다. 프론트 수정·메시지 전송은 하지 않았다.
- 미완료: FC023 프론트 수정/실제 빌드와 실계정 웹·iOS·Android 왕복·전체 정산·종료, CTO 리뷰 후 병합·배포. 면제/스푼/푸시/WebSocket·FC012를 새로 확정하지 않는다.
- 정책 기준: origin/main 3eb5254의 열림 FC005/009/010/011/014/015/020/021을 확인했고 관련 후속을 유지한다. 새 학습 기록은 최종 main→후보 diff에 고정하며 기존 PR 아카이브를 보존한다.
