# 2026-10-19 출시 후보 — OCR 보류

확정했다. 새 사진 수신도 이번 출시 범위에서 제외한다. 기존 완료 기록은 [10/18](RELEASE_2026_10_18.md)을 유지한다.

앱/서버 코드·스키마·계산은 #37과 같고 Caddy 설치/검증·CI·문서가 합쳐진다. 충돌은 DEVLOG와
ADR 인덱스 두 곳뿐이었고 양쪽 결정을 모두 보존했다. 통합 커밋은 `08b28b2`다.

미커밋 상태로 보존했다. 별도 세션의 Python 작업 트리는 수정하지 않는다. 후보에는 receipt-ocr,
Spring receipt 패키지, 사진 API·설정·의존성이 들어 있지 않다. 후보 API 계약은 v12다.

## 현재 검증 근거

통합 후보의 Core·서버 전체 테스트·bootJar와 실제 MySQL/HTTP·기존 DB 전환·Caddy 경로를 같은
PR CI에서 검증한다. 로컬 실행과 CI 결과는 `docs/pr-reviews/2026-10-19-release-candidate/`에
보존한다. 기존 PR의 성공을 통합 후보의 새 CI 성공으로 대신 기록하지 않는다.
