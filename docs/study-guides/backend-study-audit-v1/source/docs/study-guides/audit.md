## OCI 읽기 전용 확인

- 사용자가 지정한 OCI 접속 주소와 준비된 키로 ubuntu SSH 접속에 성공했다. origin IP나 키를 공개 저장소에 적지 않는다.
- ARM64 서버이며 ~/jeongsan 배포 디렉터리는 없다. 따라서 해당 경로에 정산 앱이 배포되었다고 보고하지 않는다.
- 기존 n8n-kafka-app-1이 호스트 127.0.0.1:8080을 점유한다. 이 주소의 health 200은 정산 앱의 기동 증거가 아니다.
- 정산 docker-compose.prod.yml도 127.0.0.1:8080을 사용한다. 운영 배포 전에 정산 전용 포트와 해당 API 프록시·터널 경로를 정해야 한다.
- 외부 API의 502와 이 관측만으로 Cloudflare 경로 설정을 확정하지 않는다. 프록시 설정·실제 정산 앱 경로는 아직 미확인이다.
- 기존 n8n/Kafka 서비스의 설정·포트·컨테이너를 변경하거나 중단하지 않았다.
