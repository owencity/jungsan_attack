# 영수증 주류 사전

한 표기는 한 행에 적습니다. 아래는 개발용 예시이며 실제 매장 표기를 CTO가 보완합니다.
종류: 소주 / 맥주 / 막걸리 / 기타주류 / 비주류. 단위: 병 / 캔 / 잔.
가격은 매장마다 달라 사전에 넣지 않습니다. 별칭은 행을 추가합니다.
무알코올 제품은 비주류로 명시합니다. 사전에 없는 이름은 추측하지 않습니다.
