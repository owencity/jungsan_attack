# 영수증 주류 실행 사전 v2

CTO 제공 문서의 브랜드·표기와 팩트체크 수정 사항을 실행용으로 옮겼다.
정책·출처·미지원 범위는 [검토 문서](../docs/receipt_alcohol_ocr_dictionary.md)를 따른다.
한 별칭은 한 행이며 NFKC·공백·대소문자만 정규화한다. 유사도·부분 문자열로 추측하지 않는다.
단위는 브랜드의 대표 포장이 아니라 **그 표기 자체가 명시한 용기**다. 브랜드만 있으면 반드시 미상이다.
생맥은 별도 제공 방식이며 잔/피처를 가정하지 않는다. 정확한 전체 비주류·비음료 이름은 제외한다.
새 별칭은 실제 사례나 제조사 근거로 검토한 뒤 추가한다. 가격은 사전에 넣지 않는다.
