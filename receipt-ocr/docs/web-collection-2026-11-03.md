# 웹 영수증 수집과 첫 대조 · 2026-11-03

사용자가 보유한 사진이 없어 **웹에서만** 확보했다. 직접 촬영본이나 계정 연결을 요구하지 않았다.
OCR 코드는 기존 `b99f7a745aacded10ec01defbd91a55171fa23ed` 그대로다. 수집/정답/비교 기록을 추가하며
현재 모델·파서·사전·API·Spring·DB·운영은 변경하지 않는다. 최신 문서 기준 main은
`8d27496270e6c8adcb78b4580d68c150f9c3cce6`이다.

## 확보한 것과 세지 않은 것

|---|---:|---|
| 개인 후기 cslee33 | 30 | 인쇄 주류·수기·카드 전표·마트를 구분, 같은 모임/재발행 묶음 유지 |
| 개인 후기 kidm 선별 | 12 | 인쇄 주류 4, 서비스/할인 1, 합계만 6, 무주류 품목 1 |
| kidm 추가 구간 | 14 | 인쇄 주류 2, 무주류 품목 1, 나머지는 합계만/전자 전표 |
| 화로구이 리뷰 | 1 | 소주 1개·항목 5000·총주문액 99520, 단가 열/병 단위 추정 없음 |
| **위 원본 합계** | **57** | 직접 시각 검토·출처·해시 고정, 정확히 같은 바이트 중복 0 |
| HF 공개 후보 | 20 | 주류 0. 실제/합성 혼합 가능성이 있어 실제 주점 평가 분모 제외 |

논리적 후보 이미지 총 87개를 확보했다. WebP→PNG 형식 변환본은 별도 원본으로 세지 않았다.
후기/리뷰 57개는 거래/매장 기준 보수적 48묶음으로 관리한다. 묶음은 확인 가능한 동시 방문·동일 상호를
보수적으로 연결한 것이며 독립 매장 48곳 인증이 아니다. 같은 사진의 다른 압축/서명 URL은 새 자료가 아니다.

**57개는 주류 명세 57개가 아니다.** cslee33에는 명확한 총액의 인쇄 주류 5, 할인 충돌 1,
같은 모임 중간계산서 2, 수기 주류 8, 카드 전표 11, 마트 주류/무주류 각 1, 미확정 주문지 1개가 있다.
웹 게시물의 ‘영수증’ 절이 글로만 된 경우, 명함/행사 사진, 음식 사진은 원본 명세로 채택하지 않았다.
기사의 같은 영수증 확대/복합 그림과 수기+카드 전표는 거래 수를 부풀리지 않는다.

현재 술자리용 인쇄 주류 대조 13개를 만들었다. 처음 목표였던 **서로 다른 일반 술집 주류 명세 30~50개**는
아직 채우지 못했다. 카드 전표/수기/마트/HF를 넣어서 그 목표를 달성했다고 보고하지 않는다.

## 재실행과 다음 작업

```powershell
# receipt-ocr 폴더, 기존 venv와 모델 캐시 사용
.venv\Scripts\python -m unittest discover -s tests
.venv\Scripts\python tools\validate_capture_campaign.py .samples/web-2026-11-03 --manifest examples/manifest.web-pubs.example.json --output reports/web-pubs-baseline.json
```

로컬 원본은 저장소에 없다. source에서 사진이 같은지 SHA-256으로 검증해야 한다. 만료된 서명 URL을
변조하지 않고 공개 원본 페이지를 다시 읽는다. 실패 사진과 정답을 바꾸거나 미인식을 성공 처리하지 않는다.
신규 수집 결과와 기존 16개 대조 기록은 별도다. 사진을 추가로 모으는 동안 기존 실패 개선을 멈출 필요는 없다.

다음 백엔드 작업은 **총액 후보/행 연결 진단 → 상품코드/다중 줄 주류 연결 → 같은 고정 사진으로 전후 비교**다.
그와 별개로 주류 명세 원본·촬영자/매장 다양성을 늘리고, 합성/수기/마트/카드만 있는 자료를 분리한다.
무료 CPU 실행 방식 비교·휴대폰 OCR 비교는 아직 실시하지 않았다. 프론트와 Spring 연결·운영 배포도 후속이다.

최신 main의 기존 열린 FC 005·009·010·011·014·015·020·021 및 신규 FC-026을 확인했다.
FC-024/025 반영 기록·FC-021/026 변경도 비교했다. 인증/실기기/정산 후속은 이번 수집으로 닫지 않는다.
Java/Kotlin·Core·스키마·API 계약 변경과 책 목차에 연결할 새 업무 구현은 없다. 자체 점검이며 타인 리뷰/병합/배포 완료를 뜻하지 않는다.
